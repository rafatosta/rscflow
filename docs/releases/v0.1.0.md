# RSCFlow 0.1.0

Primeira versão pública do RSCFlow, uma aplicação web local para organizar projetos de
Reconhecimento de Saberes e Competências e produzir os documentos do processo a partir dos mesmos
dados estruturados.

## Principais recursos

- cadastro dos dados docentes, formação, requisitos e lançamentos nos níveis RSC I, II e III;
- armazenamento local dos projetos e dos arquivos comprobatórios no navegador;
- pontuação provisória por requisito quando o catálogo ainda depende de validação humana;
- geração do Memorial Descritivo e dos formulários e anexos normativos;
- consolidação determinística dos comprovantes, com mapa de páginas compartilhado pelos documentos;
- geração conjunta dos artefatos e pacote final ZIP com os PDFs separados;
- backup restaurável `.rscflow`, incluindo dados estruturados e arquivos binários;
- importação e exportação do JSON portátil, que permanece independente dos binários.

## Estado normativo

O catálogo normativo desta versão permanece identificado como pendente de validação humana. As
pontuações calculáveis são apresentadas como provisórias, os totais dependentes dessa validação
permanecem indisponíveis e conflitos normativos registrados continuam bloqueados. Os documentos
preservam explicitamente essas condições sem atribuir validade administrativa ao resultado.

## Privacidade e armazenamento

O processamento e a geração dos documentos ocorrem localmente no navegador. Projetos e
comprovantes ficam no armazenamento local do navegador utilizado; o backup `.rscflow` permite
transportar ou restaurar o projeto completo.

## Publicação

O site desta versão é construído a partir da tag `v0.1.0` quando esta release é publicada. O fluxo
de publicação não é acionado por pushes ou pull requests.
