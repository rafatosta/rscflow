# Documentação para mantenedores

Esta área preserva planos, auditorias e decisões históricas úteis para manutenção, mas que não
descrevem necessariamente o estado vigente. Agentes só devem consultá-la quando uma tarefa exigir a
origem ou a evolução de uma decisão.

O fluxo atual de desenvolvimento permanece em `../development-workflow.md`; arquitetura, domínio e
regulação permanecem nos documentos especializados de `docs/`.
